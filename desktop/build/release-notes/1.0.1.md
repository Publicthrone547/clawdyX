clawdyX 1.0.1 runs on **macOS and Windows** with the same features: a private Telegram bot for the Claude Code you already use, and a desktop app to set it up and watch it. Every setting is now edited in the app, and a Help screen explains everything for the system you run.

Check the files against `SHA256SUMS`. The files are not code-signed yet: on macOS click **Open Anyway** in System Settings → Privacy & Security, on Windows **More info → Run anyway**.

## What's new

1.0.1 is the first published 1.x release (the v1.0.0 tag was never released).

- **Windows is supported**, not a preview: an installer without administrator rights, a background worker that starts at login without a console window and restarts after a crash, screenshots and Claude's mouse and keyboard tools on every monitor, the camera (`/cameras`, `/camera`, `/camera video`), a Git Bash setting for Claude Code, and a Windows deny list that also removes Claude Code's PowerShell tool. Settings move to `%APPDATA%\clawdyx` automatically, the token included.
- **Every setting in the app**, including Claude Code's location, limits, the child PATH, workspace command rules, folders and retention; reset per section, export and import; editing works while the worker is stopped.
- **Help** in the app for your system; the bot's replies use your system's words too.
- **About** shows the system, the worker service and the folders, and copies a redacted diagnostics report; the update check offers the right file; optional notifications.
- **Upgrading from 0.4.x** keeps your settings, sessions and token; there is no database migration.

Linux support is in the code but not released yet.

The full list is in `CHANGELOG.md`.

- The files are not signed or notarized.
